# Method

The system has three explicit layers. Qwen3-4B-Instruct-2507 or SpikingBrain-2.0-instruct is the Planner policy: it receives the current observation, phased strategic instruction, remaining build-order items, the canonical action table, and a one-shot output example. It returns one near-term segment of at most six canonical bullet actions. The strategic layer maintains the phased BO and supplies the remaining items. The System-v1 Executor maps accepted actions to SC2 commands and retains its scripted macro and automatic combat behavior. The canonical fixed opening can finish a game without consuming a Planner action; such games contribute outcomes but no PPO policy samples.

The released Planner protocol is `legacy`. A response is enclosed in `<answer>` tags, starts with `Here are the Build Orders with attack instructions:`, and contains one exact current-list action per bullet. Quantities, aliases such as `barrack`, explanations, and invented actions are rejected. Thinking is disabled at the Qwen chat-template boundary and `<think>` output is forbidden by the environment. Strategic memory, tool queries, automatic Marine production, and forced attacks are disabled.

Training uses GiGPO with mean-normalized step advantages. Each update launches eight SC2 rollouts from one data row; the HF generation engine samples one response per environment with temperature 0.4, top-p 0.9, and a 96-token response limit. The actor uses FSDP across the configured four or eight GPUs, learning rate `1e-6`, gradient clipping at 1.0, PPO clipping `[0.2, 0.28]`, entropy coefficient 0.001, and a KL loss coefficient of 0.01 against the reference policy. The discount is 0.95 and invalid actions receive a 0.1 penalty. Padding removal is disabled because this Qwen path was validated with the padding-safe numerical implementation.

The environment is Terran versus the built-in Terran Level 5 (`Hard`) AI with `AIBuild.Air` on Flat128. `SC2_DIFFICULTY=Harder` selects Level 6. Games now end naturally with `SC2_MAX_STEPS=0`; an explicitly configured interaction cap is a truncation, not an SC2 defeat. Per-call state shaping defaults to off. Victory contributes +20 and defeat contributes -50, with bounded state and format shaping from the released environment. The reported `episode/success_rate` is the fraction of the eight training rollouts won at an update; `episode/reward/mean` averages only trajectories represented by real policy samples. Their populations may differ.

The historical 81.38% r6 result is not a measurement of the new integrated defaults and must be interpreted with the system boundary intact. The model selects BO segments, but the Executor supplies substantial low-level reliability through scripted production, defense, reinforcement, target selection, and automatic combat. Comparisons intended to establish an architecture advantage must give every model the same prompt, Planner protocol, Executor, reward, rollout budget, seeds, tokenizer controls, and search budget.
